### ADR-0001：采用最小化协作规范与项目知识体系

- 日期：2026-08-08
- 状态：已采用
- 背景：用户要求下载 `ai-software-development-specification` 并在当前项目执行相关规范，同时融合已有 `AGENTS.md`。
- 决策：引入协同规范、项目知识目录、结构校验脚本和项目 README；保留原有 GitHub 代理排障经验并将其融合到 `AGENTS.md` 与问题记录。
- 取舍与影响：不复制不适用于文档项目的软件 API、部署或发布实现；相应文件明确记录“不适用”，保留结构一致性和跨对话恢复能力。
- 依据：当前项目只有 Markdown 规范和 Git 远程，不存在应用代码、API 或部署目标。

### ADR-0002：GitHub 代理限定为仓库级配置

- 日期：2026-08-08
- 状态：已采用
- 背景：直连 GitHub 超时，Clash Verge 的实际可用端口为 `127.0.0.1:7897`。
- 决策：只使用 `git config --local` 设置 HTTP/HTTPS 代理。
- 取舍与影响：避免影响用户其他仓库和系统网络；若 Clash 端口改变，需要重新探测并更新本地配置。
- 依据：经 `git ls-remote --heads` 与 `git push -u origin main` 验证。
