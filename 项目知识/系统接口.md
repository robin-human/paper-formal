# 系统接口

状态：已确认
最后更新：2026-08-08

## 外部接口

本项目没有应用 API。唯一外部集成是 GitHub Git HTTPS 远程 `origin`，用于版本托管与推送。

## 内部模块接口

各 Markdown 文件通过相对链接和在 `AGENTS.md`、`项目知识/索引.md` 中定义的读取顺序协作；没有运行时函数或网络接口。

## 事件与消息

不适用。需求、故障、决策和任务状态变化通过更新对应项目知识文件体现。

## 数据契约与兼容性

文档必须使用 UTF-8；脚本假定根目录存在规定的协作文件和 `项目知识/` 结构。Git 代理地址属于本地 Git 配置，不得写入文档数据或提交历史。

## 接口验证方式

- 运行 `node scripts/verify-collab-spec.mjs` 验证文档结构。
- 运行 `git status --short --branch` 验证分支跟踪状态。
