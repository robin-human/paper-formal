# 系统架构

状态：已确认
最后更新：2026-08-08

## 技术栈与运行环境

项目是 Markdown 文档与 Git 仓库，不包含应用运行时。结构校验使用 Node.js 执行 `scripts/verify-collab-spec.mjs`；论文项目创建和编译要求由 `论文人机交互写作规范.md` 定义。

## 模块与边界

- `论文人机交互写作规范.md`：论文项目生成与 LaTeX 写作的权威规范。
- `AGENTS.md`：当前项目智能体入口、读取顺序和 GitHub 代理操作规则。
- `人机协同工作规范.md`：长期协作、质量和安全底线。
- `项目知识/`：项目事实、状态、决策和经验，不能替代主规范。
- `scripts/verify-collab-spec.mjs`：检查协作规则的必需文件和关键约束。

## 关键数据流

用户需求 -> 写作规范 -> LaTeX 项目与 PDF 交付；协作任务 -> 项目知识更新 -> 结构校验 -> Git 提交与远程推送。

## 部署与配置

不适用。GitHub 远程为版本托管目标；代理仅写入本仓库 `.git/config`，不纳入版本控制。

## 架构约束

- 正文规范与项目知识文件各有唯一职责，避免重复或冲突的权威来源。
- 不将临时下载的外部规范仓库纳入当前项目版本库。
