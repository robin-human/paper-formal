## 条目

### 2026-08-08：GitHub 命令行无法直连，但浏览器可访问

- 现象：`git push` 连接 `github.com:443` 超时；浏览器可以访问 GitHub。
- 原因：Clash Verge 实际监听 `127.0.0.1:7897`，而用户提供的 `127.0.0.1:7890` 没有服务监听。浏览器的网络路径不会自动传递给 Git。
- 处理：使用 `netstat -ano -p tcp` 确认 `verge-mihomo` 的监听端口；以 `git config --local` 为当前仓库配置 `http.proxy` 和 `https.proxy`，均指向 `http://127.0.0.1:7897`。
- 验证：`git ls-remote --heads` 成功，随后 `git push -u origin main` 成功创建远程分支。
- 预防：连接失败时先检查代理监听端口并测试远程引用；只配置仓库级代理，不提交凭据或假定默认端口。
